# Фирменная тема навигатора

Источник — предоставленный владельцем архив `frontend-brand.tgz`, 12.11.2026. SHA256: `904780db9b8a39671939560e013793e043eb76de4be68e640803f282c8af0ce5`.

Взяты палитра из `brand.scss` и `brand-palette.ts`, локальные Manrope 400–800 (кириллица и латиница, OFL) и `favicon.ico`. Шрифты и favicon скопированы без изменения. Вложенный `AGENT.md` описывает другой фронт на Angular; его команды не выполнялись.

Базовые токены SCP сохранены в первом `:root` файла `src/theme/tokens.css`. Блок `:root:root` ниже меняет их для всех существующих React-компонентов. Имена старых псевдонимов сохранены; полная шкала фиолетовых акцентов и шрифтовые сокращения переопределены.

В исходном архиве нет полной шкалы состояний React-кнопок. Для hover использован тёмный оттенок меню `#0c1f4f`, для active — `#04143a`. Красная кнопка использует читаемый тёмный оттенок ошибки `#c4002a`; её hover и active смешивают этот цвет с тёмным фирменным. Это адаптация состояний навигатора. Радиусы, размеры, порядок фокуса и взаимодействия сохранены.

Значение `--scp-content-secondary` не заменяется светлым фоном из Angular-темы: в навигаторе это текстовый токен. Подписи уровней отчёта остаются видимыми и сохраняют смысл. Условного форматирования произвольных гридов и меню платформы здесь нет, поэтому их Angular-патчи не перенесены.

Пути к шрифтам и favicon относительные: сборка работает в подкаталоге GitHub Pages и в iframe. Внешние шрифтовые сервисы не используются. Данные сценариев, ссылки и логика приложения не менялись. Макеты `design/` остаются историческим образцом геометрии; актуальные цвета и шрифт заданы в SPEC §5.
