# In.Plan Demo Navigator

Навигатор демо-сценария: сценарии показа In.Plan хранятся в каталоге — общие (файлы в `scenarios/`) и мои (загружены из Excel в этом браузере) — и показываются как схема блоков и карточки шагов. Из шага открывается экран In.Plan и место шага на карте процесса (In.Plan Process Map). Статический бандл без бэкенда, встраивается в вики через `iframe`.

- Требования — [PRD.md](PRD.md), техническая спецификация — [SPEC.md](SPEC.md) (главнее PRD).
- Правила разработки, beads и субагенты — [CLAUDE.md](CLAUDE.md), SPEC §10.
- Макет — `design/` (Claude Design, только чтение).
- Общие сценарии — папка `scenarios/`; первый — `scenarios/deployment-demo.xlsx`. Имя файла латиницей через дефис — это id сценария в ссылке `?scenario=`.
- Файлы в `scenarios/` публикуются вместе с приложением — без имён заказчиков.

## Старт разработки

```bash
git init && bd init --prefix DN && bd hooks install --beads
./scripts/bd-backlog.sh      # бэклог SPEC §10.6
bd ready
```

Разделы «Сборка», «Шаблон Excel», «Снимок карты процесса», «Встраивание» дописываются в задаче DN-19.
