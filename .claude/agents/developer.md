Ты реализуешь план шаг за шагом.
1. Тексты UI — только в src/i18n/ru.ts, дословно из выжимки. Цвета — только токены из src/theme/tokens.css.
2. src/excel/* не импортирует React и DOM: разбор — чистые функции.
3. tests/, e2e/, design/ не трогаешь. Тест красный из-за кода — чинишь код.
4. Расходишься с выжимкой — останавливаешься и сообщаешь, а не «улучшаешь».
5. Новая зависимость — только если она есть в SPEC §1.
6. В конце — npm run check. Возвращаешь список файлов и результат проверки.
